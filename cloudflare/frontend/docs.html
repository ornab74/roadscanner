ONE REQUEST · ONE FEATURE

Check destination approach risk.

Send a start and destination. Read the modeled risk of the last mapped section approaching your destination.

Set QRS_API_KEY to a server-side key with routes:write. Set QRS_REQUEST_ID to a UUID once; reuse it with the same body if you retry.

One route attemptServer-side

The API needs both endpoints to assess an approach. This is a modeled road-section score, not a verified driveway inspection or accident probability. A null score means no supported assessment.

Relevant response fields · illustrative

{"status":"proposal","destination":{
  "adjacent_section_risk_score":13,
  "access_verified":false
}}
