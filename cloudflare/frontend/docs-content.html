Scan API

Authenticate with Authorization: Bearer YOUR_API_KEY. Scans require an Idempotency-Key of 16–128 characters. A successful scan costs one credit; failed inference refunds the reservation.

GET /api/v1/account
POST /api/v1/scans
Content-Type: application/json
Idempotency-Key: a-unique-request-identifier

This deployment supports openai (GPT-5.5, when configured) and llama_local, in English. OpenAI calls use the configured OpenAI account directly. Other providers and translations return an unavailable response before charging. Reports are encrypted in private storage. New accounts start with no credits; purchases are disabled during the initial launch.
