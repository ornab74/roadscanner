Scan API

Authenticate with Authorization: Bearer YOUR_API_KEY. Scans require an Idempotency-Key of 16–128 characters. A successful scan costs one credit; failed inference refunds the reservation.

GET /api/v1/account
POST /api/v1/scans
Content-Type: application/json
Idempotency-Key: a-unique-request-identifier

{"latitude":40.758,"longitude":-73.9855,
 "vehicle_type":"car","destination":"Midtown",
 "model":"llama_local","language":"en",
 "weather":"rain","traffic":"slow",
 "road_type":"city street","obstacles":"none observed",
 "sensor_notes":"user observations"}

This deployment supports openai (GPT-5.5, when configured) and llama_local, in English. OpenAI calls use the configured OpenAI account directly. Other providers and translations return an unavailable response before charging. Reports are encrypted in private storage. New accounts start with no credits; purchases are disabled during the initial launch.

Garage & aircraft API

Use the same private Bearer key with /api/v1/garage/vehicles and /api/v1/aviation/snapshot. See the OpenAPI specification for schemas, quotas and all endpoints. Browser equivalents omit /v1 and require a session plus CSRF for mutations.

POST /api/v1/garage/vehicles
{"name":"My aircraft","kind":"aircraft","make":"Example","model":"Trainer",
 "theme":"winter","specs":{"true_airspeed_kt":110,"fuel_burn_per_hour":9,
 "fuel_capacity":45,"fuel_unit":"gal","reserve_minutes":45}}

POST /api/v1/aviation/snapshot
{"vehicle_id":"YOUR_VEHICLE_UUID","start":{"latitude":34.8956,"longitude":-82.2189},
 "destination":{"latitude":35.4362,"longitude":-82.5418},"departure_airport":"KGSP",
 "arrival_airport":"KAVL","altitude_ft":5000,"usable_fuel":35}

Specs and fuel reserve are user-supplied scenario inputs, not recommended operating values or legal minimums. Aircraft briefings are advisory only: no clearances, conflict avoidance, approved flight plan, terrain/airspace validation or go/no-go decision. Check independent provider status and timestamp fields. Traffic absence does not prove clear airspace.

Generate a private illustration with POST /api/v1/garage/vehicles/{id}/image, body {}, and a unique Idempotency-Key. GPT Image 2 uses one existing scan credit on success, and PHF must pass before and after generation. Failures refund the reserved credit. Images remain encrypted and owner-restricted. Holiday themes are visual illustrations only.

OpenSky traffic is limited-area crowdsourced surveillance. OpenSky OAuth credentials can be configured server-side for higher quotas. Sources: OpenSky Network, NOAA Aviation Weather Center, Open-Meteo (CC BY 4.0), and RainViewer. Provider usage/licensing limits apply.
