Start the application (local Docker)
----------------------------------
Use this command to run the container locally:

`docker run -it -p 3000:3000 --env-file /home/user/roadscanner.env -v /var/data:/var/data roadscanner:latest`

Notes
-----
- The `--env-file` path `/home/user/roadscanner.env` is an example absolute path; replace with a project-specific or user-local path as needed.
- Mounts the host `/var/data` directory into the container at `/var/data` for persistent data access; ensure the host directory exists and has appropriate permissions.
- Port `3000` is exposed on the host; change port mapping if it conflicts with other services.
