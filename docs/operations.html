Operations

1. Secrets

Generate distinct random values of at least 32 bytes for INVITE_CODE_SECRET_KEY, QRS_API_KEY_PEPPER, and QRS_LLAMA_API_TOKEN. Configure STRIPE_SECRET_KEY and STRIPE_WEBHOOK_SECRET only in the Roadscanner runtime secret store. Never place secret values in Compose files or images.

2. Stripe

Create one recurring Price and one one-time credit-pack Price. Set STRIPE_PRICE_PRO and STRIPE_PRICE_CREDITS. Register https://APP_HOST/billing/webhook and subscribe it to Checkout completion, invoice paid, and customer subscription lifecycle events. Use Stripe test mode first.

3. Local model

docker compose --profile model-download run --rm llama-model-init
docker compose up -d llama-scanner roadscanner docs

The fetch job downloads only the configured HTTPS artifact and publishes it after its pinned SHA-256 digest matches. The runtime mounts the verified model read-only.

4. Cloudflare

Keep the application route pointed to http://roadscanner:3000. Add a separate docs hostname whose service is http://docs:8080. Do not create a public route for llama-scanner.

5. API keys

Users buy credits or activate the paid plan, then create a key on /billing. The full key is shown once. Clients must send Authorization: Bearer … and a unique Idempotency-Key on each scan request.
