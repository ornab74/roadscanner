Security architecture

Internet → Cloudflare Tunnel → roadscanner:3000
                                   │
                                   └─ signed request → llama-scanner:8080

Internet → Cloudflare Tunnel → docs:8080
  • Roadscanner owns accounts, encrypted reports, Stripe webhooks, API keys, the credit ledger, and provider routing.
  • Llama scanner is on an internal-only Docker network, publishes no host port, accepts only a bounded road-scene schema, and authenticates each request and response with replay-resistant HMAC envelopes.
  • Docs is a static, read-only container. It receives no application volume or credentials and does not join the model network.
  • Cloudflare remains the public ingress. Its tunnel credential is materialized only for the connector, never for the web or docs process.

Billing invariants

  • Browser redirects never grant credits.
  • Only a valid, fresh Stripe webhook can mutate a plan or add purchased credits.
  • Stripe event IDs and credit ledger references are unique.
  • API scans reserve one credit in an immediate transaction before inference and refund once on an internal failure.
  • An idempotency key maps to one debit and one saved response per API key.
